# External Resources

For users looking to dive deeper into the technologies and standards used in OpenHW Studio, we have curated a list of external resources, official documentation, and technical standards.

## Official Hardware Documentation

* [Arduino Documentation](https://docs.arduino.cc/) - The official home for Arduino language references, tutorials, and hardware specs.
* [Raspberry Pi Pico Documentation](https://www.raspberrypi.com/documentation/microcontrollers/) - Datasheets and C/C++ SDK documentation for the RP2040.
* [STMicroelectronics Resource Center](https://www.st.com/en/microcontrollers-microprocessors/stm32-32-bit-arm-cortex-mcus.html) - Extensive technical notes on the STM32 architecture.

## Web Technologies & Standards

* [MDN Web Docs](https://developer.mozilla.org/) - The definitive resource for modern web standards, JavaScript, and browser APIs.
* [WebAssembly (Wasm)](https://webassembly.org/) - The portable compilation target that enables us to run emulators compiled from C++ natively in the browser.
* [W3C WebSockets Standard](https://www.w3.org/TR/websockets/) - The standard powering our real-time classroom synchronization.

## Electronics Tutorials & Guides

* [SparkFun Tutorials](https://learn.sparkfun.com/tutorials) - Excellent, easy-to-read guides on protocols like I2C, SPI, and UART.
* [Adafruit Learning System](https://learn.adafruit.com/) - High-quality guides for interfacing with hundreds of different sensors and breakout boards.

## Open Source Development

* [Open Source Initiative (OSI)](https://opensource.org/) - Information on open-source licenses and definitions.
* [Choose a License](https://choosealicense.com/) - A helpful resource for understanding the differences between MIT, GPL, Apache, and other licenses we use.
