## Overview
The Nano is the most popular Arduino board for permanent or semi-permanent projects where the bulky form factor of the Uno is not viable. In the OpenHW Studio simulator, you can use the Nano identically to the Uno.

## Configurable Attributes
*This component acts as the main execution unit in the simulator and has no standard configurable attributes.*

## Working Principle
The Nano is built around the ATmega328P microcontroller. It executes standard Arduino C/C++ code. It differs from the Uno primarily by exposing two additional analog pins (`A6` and `A7`), which are present on the surface-mount version of the ATmega328P used on the Nano.

## Wiring Diagram
1. The Nano is designed to straddle the center divider of a breadboard, exposing its pins to rows on either side.
2. Provide power via the USB port, or supply 7-12V to the **VIN** pin (and Ground to **GND**).
3. Connect sensors to the analog or digital pins exactly as you would on a standard Arduino Uno.

## Example Arduino Code
```cpp
// Blinking the built-in LED (Pin 13)
void setup() {
  pinMode(13, OUTPUT);
  Serial.begin(9600);
  Serial.println("Nano Initialized!");
}

void loop() {
  digitalWrite(13, HIGH);
  delay(500); // Faster blink
  digitalWrite(13, LOW);
  delay(500);
}
```

## Simulation Notes
- In the simulator, the Nano executes code exactly like the Uno.
- Be careful with `A6` and `A7`—while the simulator may technically allow `digitalRead` on them, hardware ATmega328P chips do not support digital operations on these two specific pins.
